# Exponential Graph Explorer  
インタラクティブに指数関数 *y = a · e^(b·x)* を学べる可視化ツール

このページでは、スライダーを動かしながら **振幅 a** と **指数 b** を変化させ、  
指数関数の形がどのように変わるかを直感的に理解できます。

👉 公開ページはこちら  
https://emikohigashi.github.io/exponential_graph/

---

## ✨ 機能
- **a（振幅）** を変更すると、グラフが縦方向に伸び縮みします  
- **b（指数）** を変更すると、成長スピードが変わります  
- **増加・減衰・反転・爆発的成長** など、さまざまなパターンをワンクリックで試せます  
- x=0 のとき、常に y = a になる理由も視覚的に確認できます

---

## 📘 数式
このツールで扱う関数は次の形です：



\[
y = a \cdot e^{b x}
\]



- a：振幅（高さ）
- b：指数（成長・減衰の速さ）
